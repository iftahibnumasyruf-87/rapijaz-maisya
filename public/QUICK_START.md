# Quick Start: Import Nilai dari Excel

## 🚀 3 Langkah Cepat

### 1️⃣ Unduh Template
- Pilih **Kelas** di Input Nilai
- Klik **"Unduh Template Excel"** (tombol biru)
- File otomatis download

### 2️⃣ Isi Nilai di Excel
- Buka file yang sudah diunduh
- Edit kolom **"[MAPEL] - UTS"** dan **"[MAPEL] - UAS"**
- Simpan file (Ctrl+S)

### 3️⃣ Impor Kembali
- Klik **"Impor dari Excel"** (tombol oranye)
- Pilih file yang sudah diisi
- Tunggu notifikasi sukses ✓

**Done!** Nilai tersimpan otomatis dengan raport terhitung.

---

## 📝 Format Nilai

| Format | Contoh | Catatan |
|--------|--------|---------|
| Latin | `85`, `90.5`, `78` | ✅ Standart |
| Arab | `٨٥`, `٩٢`, `٧٨` | ✅ Auto-konversi |
| Kosong | (biarkan kosong) | ✅ OK jika tidak ada nilai |
| Desimal | `85.5` atau `85,5` | ✅ Keduanya OK |

**Jangan gunakan:** Angka teks ("delapan puluh lima"), simbol khusus, formula Excel

---

## ⚠️ Persyaratan

✅ Pilih kelas dulu  
✅ Pastikan ada mata pelajaran untuk kelas itu  
✅ Gunakan template dari aplikasi (jangan manual)  
✅ Jangan ubah kolom NIS & Nama Santri  
✅ Format file: `.xlsx` atau `.xls`

---

## ❓ Error?

**"Pilih kelas dulu!"**  
→ Pilih kelas di dropdown atas

**"Siswa tidak ketemu"**  
→ Cek NIS/Nama siswa, harus sama persis dengan database

**"Format Excel salah"**  
→ Unduh template baru, jangan edit struktur kolom

**"File rusak"**  
→ Coba Excel (bukan Google Sheets), simpan format `.xlsx`
