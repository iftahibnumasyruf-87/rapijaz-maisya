## 🚀 Quick Start (3 Langkah)

### Step 1: Unduh Template
```
Menu: Input Nilai → Pelajaran
Pilih: Kelas
Klik: "Unduh Template Excel" (biru)
```

### Step 2: Isi di Excel
```
Buka file yang diunduh
Edit: Kolom UTS & UAS
Simpan: File Excel
```

### Step 3: Impor Kembali
```
Klik: "Impor dari Excel" (oranye)
Pilih: File yang sudah diisi
Tunggu: Notifikasi sukses ✓
```

**Done! Nilai tersimpan otomatis** ✓
